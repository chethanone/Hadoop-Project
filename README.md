# Hadoop File Management and MapReduce Visualization System

## Overview

This project provides a **web-based interface** for interacting with a Hadoop cluster (HDFS, YARN) running in WSL2 Ubuntu. Users can:
- Browse and manage files on HDFS with safety guardrails.
- Submit, monitor, and view results of three MapReduce jobs (**WordCount**, **MatrixMultiplication**, **WeatherAnalysis**).
- View a dashboard with real‑time HDFS storage statistics and recent job statuses.

The backend is built with **Flask**, the UI uses **Bootstrap 5** with a dark theme, and the MapReduce jobs are packaged in `jars/mapreduce-jobs.jar`.

## Prerequisites

- **Windows 10/11** with **WSL2** installed.
- Ubuntu distribution in WSL2.
- Hadoop 3.5.0 installed in WSL2 (`/home/chethan/hadoop-3.5.0`).
- Python 3.10+ with a virtual environment (`hadoop_proj_venv`).
- Java JDK 8+ for building the MapReduce JAR.

## Setup (Windows)

1. **Open PowerShell** as your user.
2. **Clone the repository** (already done) at `C:\hadoop_proj`.
3. **Create and activate the virtual environment**:
   ```powershell
   cd C:\hadoop_proj
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
4. **Build the MapReduce JAR** (run inside WSL2):
   ```powershell
   wsl.exe -d Ubuntu -- bash -lc "cd /mnt/c/hadoop_proj && ./compile_mapreduce.sh"
   ```
   The JAR will appear at `jars/mapreduce-jobs.jar`.
5. **Start Hadoop services** in WSL2 (NameNode, DataNode, ResourceManager, NodeManager). Follow the standard Hadoop start scripts in `/home/chethan/hadoop-3.5.0/sbin`.
6. **Run the Flask app**:
   ```powershell
   python run.py
   ```
   The server listens on `http://127.0.0.1:5000`.

## Using the Application

- **Dashboard** – Visit `http://127.0.0.1:5000/dashboard/` to see HDFS storage usage and recent jobs.
- **MapReduce Lab** – Visit `http://127.0.0.1:5000/mapreduce/` to submit jobs, watch progress, view logs, and download results.
- **File Manager** – Accessible via the navigation bar; all operations are sandboxed under `/user/chethan/` and protected against accidental deletion of the baseline files.

## FAQ & Troubleshooting

- **Hadoop not reachable?** Ensure the WSL2 services are running and the ports `9000` (namenode RPC), `9870` (Web UI), and `8088` (ResourceManager) are open.
- **MapReduce job fails?** Verify `jars/mapreduce-jobs.jar` contains the three job classes (`WordCount`, `MatrixMultiplication`, `WeatherAnalysis`). Re‑run `compile_mapreduce.sh` if needed.
- **Static assets missing?** The `static/js` folder contains `dashboard.js` and `mapreduce.js`. They are loaded automatically via Flask's `url_for('static', ...)`.
